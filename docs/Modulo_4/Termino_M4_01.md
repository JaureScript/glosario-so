# PML5 / Page Map Level 5 (PML5)
**Definición formal:** 
Extensión de la jerarquía de paginación de la arquitectura x86_64 que introduce un quinto nivel de tabla de páginas para ampliar sustancialmente el espacio de direcciones virtuales direccionable[cite: 3].

**Rol Operativo / Utilidad:** 
Amplía la capacidad de *abstracción* de memoria del sistema operativo, permitiendo al *árbitro* gestionar servidores con cantidades masivas de RAM física, lo cual optimiza el *rendimiento* en aplicaciones de *hardware* a gran escala[cite: 4].
