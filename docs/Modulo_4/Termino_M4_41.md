# Sistema de Archivos / File System
**Definición formal:** 
Componente del sistema operativo encargado de organizar, almacenar, recuperar y gestionar los archivos y sus metadatos en los dispositivos de almacenamiento secundario[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como la *abstracción* principal del almacenamiento, traduciendo bloques lógicos en direcciones físicas de *control de hardware*. Funciona como un *árbitro* que garantiza el *rendimiento* en el acceso a datos y asegura las políticas de *seguridad* a través de listas de control de acceso[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
