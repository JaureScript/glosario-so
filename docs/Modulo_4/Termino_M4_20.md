# Registro de Estado (Flags) / Status Register (Flags)
**Definición formal:** 
Conjunto de bits individuales dentro de un registro de la CPU que reflejan el estado actual de la operación aritmética o lógica más reciente (ej. cero, desbordamiento, signo)[cite: 3].

**Rol Operativo / Utilidad:** 
Instrumento esencial de *control de hardware*. Permite al sistema operativo evaluar interrupciones y excepciones de *seguridad* matemática (como división por cero o desbordamientos), disparando la intervención del *árbitro* para proteger la integridad del núcleo[cite: 4].
