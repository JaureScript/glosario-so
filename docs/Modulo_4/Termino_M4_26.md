# RTOS (Real-Time Operating System) / RTOS
**Definición formal:** 
Sistema operativo diseñado específicamente para procesar datos y eventos con restricciones de tiempo estrictas y deterministas[cite: 3].

**Rol Operativo / Utilidad:** 
Impone un *control de hardware* milimétrico. El *árbitro* prioriza el cumplimiento de latencias temporales críticas (determinismo) por encima del *rendimiento* general, garantizando la máxima *seguridad* en entornos donde un retraso podría causar un fallo físico catastrófico[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
