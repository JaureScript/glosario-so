# Placa Base / UEFI / UEFI Motherboard Firmware
**Definición formal:** 
Firmware moderno basado en estándares abiertos que sustituye al BIOS tradicional, ofreciendo soporte para discos de gran capacidad, arranque seguro y una interfaz gráfica avanzada[cite: 3].

**Rol Operativo / Utilidad:** 
Establece la raíz de confianza de *seguridad* y el *control de hardware* primario antes de ceder la ejecución al gestor de arranque, abstrayendo las complejidades de inicialización del *hardware* físico subyacente[cite: 4].
