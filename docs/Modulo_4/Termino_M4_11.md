# Proceso / Process
**Definición formal:** 
Instancia de un programa de computadora en ejecución, que incluye el código actual, los datos, el contador de programa, los registros de la CPU y los recursos asignados[cite: 3].

**Rol Operativo / Utilidad:** 
Constituye la unidad central de *abstracción* del sistema operativo. El núcleo actúa como *árbitro*, asignando cuotas de *control de hardware* (CPU y RAM) mientras mantiene barreras de *seguridad* estrictas entre las distintas instancias en ejecución[cite: 4].
