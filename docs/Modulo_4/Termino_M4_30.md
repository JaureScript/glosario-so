# Segmento de Datos / Data Segment
**Definición formal:** 
Sección de un programa ejecutable que almacena las variables globales y estáticas que han sido explícitamente inicializadas con un valor determinado[cite: 3].

**Rol Operativo / Utilidad:** 
Permite una *abstracción* eficiente en la carga de binarios. Facilita el *control de hardware* y mejora el *rendimiento* ya que el *árbitro* del SO conoce exactamente el tamaño en disco y en memoria requerido, asignando los permisos de *seguridad* (lectura/escritura) adecuados de manera nativa[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
