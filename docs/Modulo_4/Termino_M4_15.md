# Protocolo NVMe (Non-Volatile Memory Express) / NVMe Protocol
**Definición formal:** 
Protocolo de comunicación de alta velocidad diseñado específicamente para acceder a unidades de almacenamiento en estado sólido (SSD) mediante buses PCI Express[cite: 3].

**Rol Operativo / Utilidad:** 
Revoluciona el *rendimiento* y el *control de hardware* de E/S. Abstrae el paralelismo nativo de la memoria flash, permitiendo al sistema operativo despachar miles de colas simultáneas de forma segura, superando los cuellos de botella de protocolos legados[cite: 4].
