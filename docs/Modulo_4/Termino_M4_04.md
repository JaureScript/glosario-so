# Página Virtual / Virtual Page
**Definición formal:** 
Bloque de tamaño fijo de direcciones virtuales generado por el espacio de direcciones de un proceso[cite: 3].

**Rol Operativo / Utilidad:** 
Es la unidad atómica de *abstracción* sobre la que opera la MMU. Permite al sistema operativo mapear lógicamente los datos hacia el *hardware* físico, aislando áreas con restricciones de *seguridad* (como solo lectura) para evitar inyecciones de código[cite: 4].
