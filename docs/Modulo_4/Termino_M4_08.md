# POSIX (Portable Operating System Interface) / POSIX
**Definición formal:** 
Familia de estándares definidos por el IEEE que especifican las interfaces de programación de aplicaciones (APIs) y el comportamiento esperado para sistemas operativos compatibles con UNIX[cite: 3].

**Rol Operativo / Utilidad:** 
Define la *abstracción* estandarizada del sistema. Garantiza que las llamadas al sistema (syscalls) operen de manera predecible, unificando el *control de hardware* y las reglas de *seguridad* para lograr una portabilidad de software absoluta a nivel de código fuente[cite: 4].

**Cita Bibliográfica formal:** Arpaci-Dusseau, R. H., & Arpaci-Dusseau, A. C. (2018). *Operating Systems: Three Easy Pieces*. Arpaci-Dusseau Books. Capítulo 15-16.
