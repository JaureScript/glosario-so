# Shmem / Shared Memory (Shmem)
**Definición formal:** 
Subsistema del núcleo Linux que implementa sistemas de archivos en memoria volátil para facilitar la comunicación eficiente entre procesos mediante memoria compartida[cite: 3].

**Rol Operativo / Utilidad:** 
Es la *abstracción* IPC de más alto *rendimiento*. Permite que el *árbitro* asigne bloques de RAM comunes a múltiples procesos, eliminando la sobrecarga de copias y el *control de hardware* de almacenamiento físico, dejando la responsabilidad de *seguridad* y sincronización a las aplicaciones de usuario[cite: 4].
