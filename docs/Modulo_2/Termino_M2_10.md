# F2FS (Flash-Friendly File System) / F2FS
**Definición formal:** 
Sistema de archivos desarrollado específicamente para dispositivos de almacenamiento basados en memoria flash NAND (como unidades SSD y eMMC), optimizando los patrones de escritura para minimizar el desgaste[cite: 3].

**Rol Operativo / Utilidad:** 
Constituye una *abstracción de hardware* altamente especializada que optimiza el *rendimiento*[cite: 4] secuencial, aplicando técnicas de registro (log-structured) para prolongar la vida útil física de las celdas de almacenamiento flash.

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
