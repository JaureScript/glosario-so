# FreeRTOS / FreeRTOS
**Definición formal:** 
Sistema operativo de tiempo real (RTOS) de código abierto, ligero y altamente portable, diseñado para microcontroladores y sistemas empotrados de recursos limitados[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como un *árbitro determinista*[cite: 4], asegurando un *control de hardware* predecible y estricto donde las tareas críticas (como frenos ABS o marcapasos) interceptan el procesador con latencias matemáticas exactas y garantizadas, priorizando seguridad sobre rendimiento global.
