# Fallo de Página / Page Fault
**Definición formal:** 
Excepción de hardware generada cuando un proceso intenta acceder a una página virtual que no está presente en la memoria física (fallo menor o mayor), obligando al núcleo a cargarla[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como un mecanismo vital de *control de hardware y abstracción*[cite: 4], permitiendo que el sistema operativo simule disponer de más memoria RAM de la físicamente instalada, gestionando el intercambio (swap) de forma transparente para las aplicaciones.

**Cita Bibliográfica formal:** Arpaci-Dusseau, R. H., & Arpaci-Dusseau, A. C. (2018). *Operating Systems: Three Easy Pieces*. Arpaci-Dusseau Books. Capítulo 15-16.
