# Init y Systemd / Init and Systemd
**Definición formal:** 
El primer proceso del espacio de usuario (con PID 1) lanzado por el núcleo de Linux durante el arranque, encargado de inicializar los servicios del sistema y actuar como el padre supervisor de todos los demás procesos.

**Rol Operativo / Utilidad:** 
Actúa como el *árbitro* supervisor definitivo de todo el entorno del usuario, manteniendo la *seguridad* y estabilidad del sistema operativo al monitorear servicios críticos, adoptar procesos huérfanos y gestionar paralelamente el *rendimiento* del arranque.
