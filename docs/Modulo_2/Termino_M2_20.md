# GPT (GUID Partition Table) / GPT
**Definición formal:** 
Estándar moderno para el diseño de la tabla de particiones de un disco de almacenamiento, que utiliza identificadores globales únicos (GUID) y soporta discos de gran capacidad superando las limitaciones de MBR[cite: 3].

**Rol Operativo / Utilidad:** 
Proporciona la *abstracción de hardware* a bajo nivel necesaria para que el sistema operativo identifique el direccionamiento lógico del disco. Mejora la *seguridad*[cite: 4] y recuperación de datos al mantener copias redundantes de la tabla estructural en los extremos del disco físico.
