# Hipervisor Tipo 1 / Type 1 Hypervisor
**Definición formal:** 
Hipervisor de tipo nativo o "bare-metal" que se ejecuta directamente sobre el hardware físico del equipo, gestionando de forma eficiente los recursos para las máquinas virtuales invitadas.

**Rol Operativo / Utilidad:** 
Maximiza el *rendimiento* y la *seguridad* al eliminar la sobrecarga de un sistema operativo anfitrión intermedio. El hipervisor asume el control directo de la CPU, la MMU y el hardware de E/S, abstrayéndolos eficientemente hacia las máquinas virtuales.
