# init.rc / init.rc
**Definición formal:** 
Archivo de configuración estructurado en scripts utilizado en sistemas operativos basados en Android para definir la inicialización y los servicios del sistema temprano durante el arranque.

**Rol Operativo / Utilidad:** 
Define las políticas base de *control de hardware* y abstracción en plataformas móviles, indicándole al proceso de inicialización qué demonios, restricciones y políticas de *seguridad* deben cargarse en memoria para estabilizar el dispositivo.
