# User Namespace / User Namespace
**Definición formal:** 
Espacio de nombres de Linux que aísla los identificadores de usuario y grupo (UID/GID), permitiendo que un proceso se ejecute con privilegios de superusuario dentro de un contenedor, pero como un usuario sin privilegios en el anfitrión[cite: 3].

**Rol Operativo / Utilidad:** 
Es el pilar de la *seguridad* en la virtualización por contenedores. El *árbitro* provee una *abstracción* donde el usuario cree poseer el *control de hardware* total, evitando que comprometa el *rendimiento* o la integridad crítica del nodo principal[cite: 4].
