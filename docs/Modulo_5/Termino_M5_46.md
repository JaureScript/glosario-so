# OOM Killer (Out Of Memory Killer) / OOM Killer
**Definición formal:** 
Rutina heurística crítica del núcleo de Linux que selecciona y termina forzosamente uno o varios procesos para liberar memoria RAM cuando el sistema se enfrenta a un agotamiento total de recursos físicos[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como el mecanismo de *seguridad* de último recurso. El *árbitro* interviene brutalmente en el *control de hardware*, sacrificando procesos menos críticos (basado en un sistema de puntuación algorítmica) para salvaguardar el *rendimiento* del núcleo y evitar el colapso absoluto de la máquina[cite: 4].

**Cita Bibliográfica formal:** Arpaci-Dusseau, R. H., & Arpaci-Dusseau, A. C. (2018). *Operating Systems: Three Easy Pieces*. Arpaci-Dusseau Books. Capítulo 15-16.
