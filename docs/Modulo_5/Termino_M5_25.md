# Windows NT / Windows NT Architecture
**Definición formal:** Arquitectura subyacente de la familia de sistemas operativos modernos de Microsoft, caracterizada por su núcleo híbrido, diseño orientado a objetos y soporte nativo para multiprocesamiento simétrico[cite: 3].

**Rol Operativo / Utilidad:** Combina el *rendimiento* de un monolítico con la *abstracción* de un micronúcleo. El *árbitro* (NT Executive) delega el *control de hardware* a subsistemas especializados, implementando estrictas listas de control de acceso (ACLs) para garantizar la *seguridad* en el espacio de usuario[cite: 4].

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
