# x86_64 (AMD64) / x86_64 Architecture
**Definición formal:** Extensión de 64 bits del conjunto de instrucciones x86 original, que amplía masivamente los registros de propósito general y el espacio de direccionamiento de memoria física y virtual[cite: 3].

**Rol Operativo / Utilidad:** Representa la base física para el *control de hardware* moderno. Obliga al *árbitro* del SO a gestionar tablas de páginas de cuatro o cinco niveles, garantizando la *abstracción* requerida para aplicaciones de alto *rendimiento* que consumen terabytes de memoria RAM de forma segura[cite: 4].

**Cita Bibliográfica formal:** Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10th ed.). Wiley. Capítulo 3-4.
