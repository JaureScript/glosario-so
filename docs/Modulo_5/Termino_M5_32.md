# ASLR (Address Space Layout Randomization) / ASLR
**Definición formal:** 
Técnica de seguridad informática implementada por el sistema operativo que consiste en alterar de forma aleatoria las ubicaciones de las áreas de datos clave de un proceso dentro del espacio de direcciones virtuales[cite: 3].

**Rol Operativo / Utilidad:** 
Es una contramedida de *seguridad* fundamental que actúa sobre la *abstracción* de la memoria virtual. El *árbitro* frustra ataques de desbordamiento al impedir que el código malicioso prediga el mapa del *control de hardware*, con un impacto nulo en el *rendimiento* de ejecución[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
