# API (Application Programming Interface) / API
**Definición formal:** 
Conjunto de subrutinas, funciones y procedimientos estandarizados que ofrece el sistema operativo para que el software de nivel superior pueda comunicarse de forma estructurada con sus servicios subyacentes[cite: 3].

**Rol Operativo / Utilidad:** 
Constituye la máxima *abstracción* para los desarrolladores. El *árbitro* expone servicios complejos de *control de hardware* a través de estas interfaces garantizando que las aplicaciones mantengan la *seguridad* arquitectónica y maximicen el *rendimiento* sin manipular registros de bajo nivel[cite: 4].

**Cita Bibliográfica formal:** Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10th ed.). Wiley. Capítulo 3-4.
