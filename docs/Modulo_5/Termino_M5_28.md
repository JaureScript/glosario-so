# XFS / XFS File System
**Definición formal:** Sistema de archivos de 64 bits con registro de transacciones (journaling), altamente escalable y optimizado para la asignación paralela y el manejo eficiente de archivos de gran tamaño[cite: 3].

**Rol Operativo / Utilidad:** Ejerce un *control de hardware* superior sobre los arreglos de discos. El *árbitro* maximiza el *rendimiento* concurrente mediante grupos de asignación independientes, asegurando la *seguridad* y consistencia estructural de la *abstracción* de almacenamiento incluso bajo caídas eléctricas abruptas[cite: 4].

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
