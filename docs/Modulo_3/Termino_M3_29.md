# Multiprogramación / Multiprogramming
**Definición formal:** 
Técnica de gestión de sistemas operativos que permite mantener múltiples programas cargados simultáneamente en la memoria principal para maximizar la utilización de la CPU alternando su ejecución[cite: 3].

**Rol Operativo / Utilidad:** 
Maximiza el *rendimiento* global del *hardware*[cite: 4]. Obliga al núcleo a operar como un *árbitro* eficiente, gestionando la memoria y despachando rápidamente procesos mientras otras aplicaciones esperan por lentas operaciones de E/S.
