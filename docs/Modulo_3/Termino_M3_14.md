# Mesa DRI / Mesa DRI
**Definición formal:** 
Capa de software de código abierto en Linux que implementa implementaciones de estándares gráficos (como OpenGL y Vulkan) y permite la aceleración por hardware mediante el controlador DRM del núcleo.

**Rol Operativo / Utilidad:** 
Funciona como interfaz de *abstracción* gráfica, traduciendo llamadas de API de alto nivel hacia operaciones nativas de GPU. Optimiza radicalmente el *rendimiento* visual delegando la carga computacional pesada al *control de hardware* específico que gestiona el kernel.
