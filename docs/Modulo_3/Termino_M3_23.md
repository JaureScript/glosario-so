# Monitor de Sincronización / Synchronization Monitor
**Definición formal:** 
Primitiva de sincronización de alto nivel que encapsula variables compartidas junto con sus procedimientos de acceso seguro, garantizando exclusión mutua implícita[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como *árbitro* a nivel de software. Simplifica la *abstracción*[cite: 4] de la concurrencia, mitigando vulnerabilidades de *seguridad* (como condiciones de carrera) al asegurar que solo un hilo modifique los recursos críticos a la vez.
