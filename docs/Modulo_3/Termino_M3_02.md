# LFU (Least Frequently Used) / Least Frequently Used
**Definición formal:** 
Algoritmo de reemplazo de páginas que expulsa aquella página que ha registrado la menor cantidad de accesos históricos durante su estancia en memoria.

**Rol Operativo / Utilidad:** 
Funciona como una política de *árbitro* para la gestión de memoria virtual, optimizando el *rendimiento* mediante la evaluación estadística del uso del *hardware*, aunque requiere una mayor sobrecarga de cómputo para mantener los contadores de frecuencia.
