# Linux Capabilities / Linux Capabilities
**Definición formal:** 
Mecanismo de seguridad de Linux que divide los privilegios tradicionales del superusuario (root) en unidades atómicas independientes y específicas, permitiendo un control de acceso más granular.

**Rol Operativo / Utilidad:** 
Implementa una capa avanzada de *seguridad* basada en el principio de menor privilegio, mitigando el impacto de procesos comprometidos al abstraer y particionar el *control de hardware* reservado históricamente a un único administrador.
