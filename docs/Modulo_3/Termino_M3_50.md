# PML4 (Page Map Level 4) / Page Map Level 4 (PML4)
**Definición formal:** 
Tabla de páginas de nivel superior (cuarto nivel) en la jerarquía de paginación de 4 niveles de la arquitectura x86_64[cite: 3].

**Rol Operativo / Utilidad:** 
Es el punto de entrada para el *control de hardware* de la MMU. Permite una *abstracción* jerárquica que soporta enormes espacios de direcciones virtuales, garantizando *seguridad* al segmentar el mapa de memoria mientras balancea el *rendimiento* mediante búsquedas estructuradas[cite: 4].

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
