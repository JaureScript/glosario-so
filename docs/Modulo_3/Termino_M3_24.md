# Monitor Residente / Resident Monitor
**Definición formal:** 
Software primitivo de control que residía en la memoria de las primeras computadoras para automatizar la transición y ejecución secuencial de trabajos (batch)[cite: 3].

**Rol Operativo / Utilidad:** 
Fue la primera *abstracción* histórica de un *árbitro*[cite: 4] de sistema operativo. Mejoró radicalmente el *rendimiento* al automatizar el *control de hardware* elemental sin requerir la lenta intervención humana entre un trabajo y otro.

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
