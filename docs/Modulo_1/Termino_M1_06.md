# AOSP (Android Open Source Project) / AOSP

**Definición formal:** 
Repositorio oficial y base de código abierto del sistema operativo móvil Android mantenido por Google[cite: 3].

**Rol Operativo / Utilidad:** 
Define la *arquitectura base y abstracción*[cite: 4] del software sobre el hardware móvil, integrando el núcleo Linux con el framework de aplicaciones de usuario en un entorno seguro.

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
