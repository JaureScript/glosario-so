# Contador de Programa / Program Counter (PC)
**Definición formal:** 
Registro especial del procesador que almacena la dirección de memoria de la siguiente instrucción que debe ser ejecutada[cite: 3].

**Rol Operativo / Utilidad:** 
Es un componente indispensable para el *control de hardware* y la gestión del *rendimiento* en el planificador. El núcleo guarda y restaura activamente este registro en cada cambio de contexto para reanudar con precisión matemática la ejecución de hilos suspendidos.

**Cita Bibliográfica formal:** Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10th ed.). Wiley. Capítulo 3-4.
