# Descriptor de Archivo / File Descriptor
**Definición formal:** 
Identificador numérico entero abstracto utilizado por los sistemas operativos tipo UNIX para referenciar un recurso de E/S abierto (archivos, tuberías, sockets de red)[cite: 3].

**Rol Operativo / Utilidad:** 
Proporciona una capa de *abstracción* esencial, permitiendo que las aplicaciones del espacio de usuario interactúen con el hardware subyacente y los flujos de datos de forma estandarizada, sin necesidad de conocer la topología física del almacenamiento o la red.

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
