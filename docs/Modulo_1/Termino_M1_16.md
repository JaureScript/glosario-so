# Bootloader / Bootloader
**Definición formal:** 
Programa de inicio encargado de cargar el núcleo del sistema operativo en la memoria principal y transferirle el control tras finalizar las rutinas de inicialización del hardware (firmware)[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como el *puente de abstracción* inicial entre el firmware estático y el núcleo dinámico, preparando el entorno de ejecución en modo protegido y montando el sistema de archivos raíz temporal (initramfs).

**Cita Bibliográfica formal:** Arpaci-Dusseau, R. H., & Arpaci-Dusseau, A. C. (2018). *Operating Systems: Three Easy Pieces*. Arpaci-Dusseau Books. Capítulo 15-16.
