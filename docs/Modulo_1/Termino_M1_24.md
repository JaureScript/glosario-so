# cgroups v2 (Control Groups) / cgroups v2
**Definición formal:** 
Característica del núcleo Linux que permite limitar, contabilizar y aislar el uso de recursos del sistema (CPU, memoria, E/S, red) para un grupo jerárquico de procesos[cite: 3].

**Rol Operativo / Utilidad:** 
Ejerce el rol de *árbitro* absoluto en la asignación de hardware. Optimiza el *rendimiento* global y la *seguridad* al prevenir monopolios de recursos (inanición), constituyendo el pilar fundamental para la limitación de consumo en la tecnología de contenedores.
