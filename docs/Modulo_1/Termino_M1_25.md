# CFS (Completely Fair Scheduler) / Completely Fair Scheduler
**Definición formal:** 
Planificador de CPU por defecto en el núcleo Linux moderno, diseñado para garantizar una distribución justa y equitativa del tiempo de procesamiento entre tareas interactivas y pesadas[cite: 3].

**Rol Operativo / Utilidad:** 
Funciona como el *árbitro* central del tiempo de procesador. Maximiza el *rendimiento* y la equidad del sistema operativo mediante el uso de árboles rojo-negro, modelando un estado ideal de CPU multitarea sin recurrir a la asignación rígida de quántums de tiempo.
