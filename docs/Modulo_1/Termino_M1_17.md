# brk() y sbrk() / brk() and sbrk()
**Definición formal:** 
Llamadas al sistema tradicionales en sistemas tipo UNIX utilizadas para modificar la ubicación del límite superior del segmento de datos (break), gestionando así la asignación de memoria dinámica del montón (heap)[cite: 3].

**Rol Operativo / Utilidad:** 
Interviene en el *control de hardware y rendimiento*, proporcionando al núcleo una interfaz directa para expandir o contraer dinámicamente el espacio de direcciones virtual asignado a un proceso en tiempo de ejecución.
