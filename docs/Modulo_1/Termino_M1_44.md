# Device Driver / Device Driver
**Definición formal:** 
Módulo de software especializado que actúa como interfaz de comunicación entre el sistema operativo y un dispositivo de hardware específico[cite: 3].

**Rol Operativo / Utilidad:** 
Es el pilar fundamental del *control de hardware*. Traduce las instrucciones genéricas, provistas por la capa de *abstracción* del núcleo, en comandos eléctricos, registros y señales especializadas comprensibles para el periférico físico objetivo.

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
