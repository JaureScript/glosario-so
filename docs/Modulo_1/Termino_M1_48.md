# Docker / Docker
**Definición formal:** 
Plataforma de código abierto basada en contenedores que automatiza el despliegue, la gestión y la ejecución de aplicaciones dentro de entornos virtuales aislados mediante contenedores OCI[cite: 3].

**Rol Operativo / Utilidad:** 
Despliega una capa de *abstracción* superior utilizando las primitivas del núcleo de Linux (namespaces y cgroups). Ofrece alta *seguridad* y aislamiento de recursos sin la pesada penalización de *rendimiento* inherente a la emulación completa de *hardware* tradicional.
