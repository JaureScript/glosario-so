# Arquitectura de E/S / I/O Architecture

**Definición formal:** 
Estructura de hardware y software encargada de mediar la transferencia de datos y la comunicación entre la unidad central de procesamiento (CPU) y los dispositivos periféricos[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como puente vital para el *control de hardware* y la *abstracción*[cite: 4], permitiendo que el sistema operativo trate diferentes periféricos mediante interfaces estándar de lectura y escritura.
