# Anomalía de Belady / Belady's Anomaly

**Definición formal:** 
Fenómeno contraintuitivo que ocurre en ciertos algoritmos de reemplazo de páginas (como FIFO), donde incrementar el número de marcos de página físicos disponibles provoca un mayor número de fallos de página[cite: 3].

**Rol Operativo / Utilidad:** 
Es una condición que afecta negativamente el *rendimiento*[cite: 4] en la gestión de memoria; su estudio es clave para que el SO implemente mejores políticas de reemplazo, como LRU.
