# Algoritmo SCAN / SCAN Algorithm

**Definición formal:** 
Algoritmo de planificación de discos (también conocido como el algoritmo del ascensor) donde el cabezal se mueve de un extremo a otro del disco atendiendo las solicitudes en su camino[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como *árbitro* en la gestión de peticiones de E/S, mejorando el *rendimiento*[cite: 4] y reduciendo el tiempo de espera frente a algoritmos básicos como FCFS.
