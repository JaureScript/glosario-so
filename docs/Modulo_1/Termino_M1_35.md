# Contenedor / Container
**Definición formal:** 
Tecnología de virtualización ligera a nivel de sistema operativo que empaqueta una aplicación junto con sus dependencias utilizando mecanismos de aislamiento del núcleo (namespaces) y limitación de recursos (cgroups)[cite: 3].

**Rol Operativo / Utilidad:** 
Proporciona una *abstracción* eficiente del entorno de ejecución, ofreciendo *seguridad* mediante el aislamiento granular de procesos y un alto *rendimiento* operativo, al compartir el mismo núcleo subyacente sin la sobrecarga del hardware virtualizado.
