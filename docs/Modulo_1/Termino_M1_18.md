# BSS (Block Started by Symbol) / BSS
**Definición formal:** 
Sección dentro de la imagen de un programa ejecutable que almacena variables globales y estáticas que no han sido inicializadas explícitamente con un valor en el código fuente (se inicializan automáticamente a cero)[cite: 3].

**Rol Operativo / Utilidad:** 
Optimiza el *rendimiento y la gestión de memoria*, ya que el sistema operativo no necesita almacenar bloques de ceros en el almacenamiento secundario; simplemente reserva y limpia el espacio en la memoria virtual al cargar el binario.
