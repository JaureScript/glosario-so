# Bit de Presencia (Present Bit) / Present Bit
**Definición formal:** 
Indicador binario dentro de una entrada de tabla de páginas (PTE) que especifica si la página virtual correspondiente se encuentra actualmente cargada en la memoria física principal[cite: 3].

**Rol Operativo / Utilidad:** 
Interviene directamente en el *rendimiento y la abstracción* de la memoria virtual, alertando a la MMU para que el procesador intercepte fallos de página únicamente cuando el bloque de memoria reside en el almacenamiento secundario.

**Cita Bibliográfica formal:** Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10th ed.). Wiley. Capítulo 3-4.
