# Colas de Mensajes / Message Queues
**Definición formal:** 
Mecanismo de comunicación entre procesos (IPC) que permite a los procesos enviar y recibir bloques estructurados de datos (mensajes) a través de una cola gestionada por el núcleo[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como capa de *abstracción* para la comunicación concurrente. Mejora el *rendimiento* y la *seguridad* al permitir la sincronización asíncrona de datos sin que los procesos compartan el mismo espacio de direcciones de memoria física.
