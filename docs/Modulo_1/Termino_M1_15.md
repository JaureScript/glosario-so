# Bit NX (No-Execute) / NX Bit
**Definición formal:** 
Característica de seguridad a nivel de hardware que marca ciertas regiones de memoria (como la pila y el montón) como no ejecutables para prevenir ataques de inyección de código malicioso[cite: 3].

**Rol Operativo / Utilidad:** 
Ejerce un control estricto de *seguridad* a nivel de hardware, bloqueando a nivel de procesador la ejecución de instrucciones en áreas designadas exclusivamente para almacenamiento de datos, mitigando vulnerabilidades críticas.

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
