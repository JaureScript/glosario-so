# AMD-V (AMD Virtualization) / AMD-V

**Definición formal:** 
Conjunto de extensiones de hardware integradas en las CPU de AMD que proporcionan soporte nativo para la virtualización eficiente de plataformas[cite: 3].

**Rol Operativo / Utilidad:** 
Mejora radicalmente el *rendimiento* y la *seguridad*[cite: 4] del sistema operativo anfitrión y del hipervisor, al delegar la ejecución de instrucciones virtuales directamente al procesador.
