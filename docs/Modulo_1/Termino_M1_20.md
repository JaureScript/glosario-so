# Btrfs (B-tree File System) / Btrfs
**Definición formal:** 
Sistema de archivos avanzado para Linux enfocado en la tolerancia a fallos, soporte para almacenamiento masivo, instantáneas (snapshots) eficientes y suma de verificación (checksums) de datos mediante árboles B[cite: 3].

**Rol Operativo / Utilidad:** 
Desempeña el rol de *abstracción de hardware y seguridad de datos*, gestionando la distribución física en los discos mientras garantiza la integridad referencial y permite recuperaciones instantáneas del estado del sistema ante corrupciones.
