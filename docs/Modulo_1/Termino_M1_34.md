# Condiciones de Coffman / Coffman Conditions
**Definición formal:** 
Conjunto de cuatro condiciones necesarias y simultáneas (exclusión mutua, retención y espera, no apropiación, y espera circular) para que ocurra un interbloqueo (deadlock)[cite: 3].

**Rol Operativo / Utilidad:** 
Constituyen el modelo analítico sobre el cual el *árbitro* de recursos del sistema operativo fundamenta sus políticas de prevención y evitación de bloqueos, garantizando el *rendimiento* continuo y la disponibilidad sostenida del hardware.
