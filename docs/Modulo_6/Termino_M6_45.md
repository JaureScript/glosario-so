# YAMA / YAMA Security Module
**Definición formal:** 
Módulo de seguridad avanzado del núcleo Linux (LSM) diseñado para restringir de forma estricta y discrecional las capacidades de depuración y modificación de memoria entre procesos (especialmente la llamada ptrace).

**Rol Operativo / Utilidad:** 
Opera como una barrera de *seguridad* lateral impenetrable. El *árbitro* bloquea el *control de hardware* malicioso de una aplicación sobre otra, fortaleciendo la *abstracción* del aislamiento de memoria del espacio de usuario sin degradar el *rendimiento* computacional.

**Cita Bibliográfica formal:** Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). *Operating System Concepts* (10th ed.). Wiley. Capítulo 3-4.
