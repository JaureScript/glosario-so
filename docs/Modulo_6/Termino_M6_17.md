# procfs (/proc) / procfs
**Definición formal:** 
Sistema de archivos virtual presente en sistemas UNIX-like que actúa como una interfaz al espacio del núcleo, exponiendo estructuras de datos y el estado de los procesos en tiempo real como si fueran archivos de texto[cite: 3].

**Rol Operativo / Utilidad:** 
Provee una *abstracción* transparente donde el *árbitro* expone el estado interno del *control de hardware* y la memoria sin comprometer la *seguridad*. Permite monitorear el *rendimiento* del sistema dinámicamente sin invocar complejas llamadas binarias[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
