# LPC (Local Procedure Call) / Local Procedure Call
**Definición formal:** 
Mecanismo de comunicación entre procesos (IPC) de alto rendimiento, nativo de Windows NT, diseñado específicamente para la transferencia rápida de mensajes entre procesos locales en el mismo equipo[cite: 3].

**Rol Operativo / Utilidad:** 
Mejora radicalmente el *rendimiento* en arquitecturas híbridas. Actúa como *abstracción* para que el *árbitro* delegue el *control de hardware* a subsistemas separados, asegurando la *seguridad* del núcleo sin la latencia de los protocolos de red tradicionales[cite: 4].
