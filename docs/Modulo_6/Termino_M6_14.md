# XNU / XNU Kernel
**Definición formal:** 
Núcleo híbrido desarrollado por Apple que combina la arquitectura del micronúcleo Mach con componentes del núcleo monolítico de FreeBSD y una robusta API orientada a objetos (IOKit)[cite: 3].

**Rol Operativo / Utilidad:** 
Fusiona la *abstracción* de alto *rendimiento* de los sistemas monolíticos con las barreras de *seguridad* de los micronúcleos. Permite al *árbitro* realizar un *control de hardware* eficiente mientras mantiene los controladores de dispositivos altamente encapsulados[cite: 4].
