# Árbol B / B-tree
**Definición formal:** 
Estructura de datos de árbol equilibrado que mantiene los datos ordenados y permite búsquedas, inserciones y eliminaciones en tiempo logarítmico, optimizada para sistemas que leen grandes bloques de datos[cite: 3].

**Rol Operativo / Utilidad:** 
Es la *abstracción* estructural predilecta para el *control de hardware* en discos magnéticos y SSDs. El *árbitro* del sistema de archivos la utiliza para sostener el *rendimiento* y la *seguridad* de la integridad referencial, minimizando costosas operaciones de búsqueda[cite: 4].
