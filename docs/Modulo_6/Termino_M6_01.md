# eBPF (Extended Berkeley Packet Filter)
**Definición formal:** 
Tecnología del núcleo Linux que permite ejecutar programas en un entorno aislado (sandbox) dentro del espacio del núcleo sin necesidad de modificar el código fuente del mismo ni cargar módulos adicionales[cite: 3].

**Rol Operativo / Utilidad:** 
Proporciona una *abstracción* revolucionaria para el *rendimiento* y monitoreo. El *árbitro* lo utiliza para ejecutar rutinas de *control de hardware* de red y telemetría de *seguridad* directamente en el Ring 0 de forma dinámica y segura[cite: 4].

**Cita Bibliográfica formal:** Tanenbaum, A. S., & Bos, H. (2014). *Modern Operating Systems* (4th ed.). Pearson. Capítulo 2-3.
