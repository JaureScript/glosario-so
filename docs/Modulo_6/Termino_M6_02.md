# Exonúcleo / Exokernel
**Definición formal:** 
Arquitectura de sistema operativo radical que minimiza las abstracciones proporcionadas por el núcleo, permitiendo a las aplicaciones gestionar directamente los recursos físicos del equipo de forma segura[cite: 3].

**Rol Operativo / Utilidad:** 
Elimina la *abstracción* tradicional forzando un *control de hardware* a nivel de aplicación para alcanzar un *rendimiento* óptimo. El *árbitro* se limita exclusivamente a multiplexar las señales y garantizar la *seguridad* física del sistema sin interferir lógicamente[cite: 4].
