# Working Set (Conjunto de Trabajo) / Working Set
**Definición formal:** 
Modelo de gestión de memoria que define el conjunto específico de páginas virtuales que un proceso está utilizando activamente en un intervalo de tiempo reciente para evitar el hiperpaginado[cite: 3].

**Rol Operativo / Utilidad:** 
Permite al *árbitro* predecir y asignar el *control de hardware* necesario para mantener un *rendimiento* óptimo, garantizando la *seguridad* de ejecución al evitar que procesos activos compitan de forma destructiva por los mismos marcos de memoria física[cite: 4].
