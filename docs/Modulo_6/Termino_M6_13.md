# Xen / Xen Hypervisor
**Definición formal:** 
Hipervisor de tipo 1 (bare-metal) de código abierto que soporta tanto paravirtualización como virtualización completa, ampliamente utilizado en infraestructuras de computación en la nube masiva[cite: 3].

**Rol Operativo / Utilidad:** 
Actúa como el *árbitro* absoluto del *hardware* físico, proporcionando *abstracción* para aislar sistemas operativos invitados con máxima *seguridad*, delegando el *control de hardware* de E/S al dominio de administración (Dom0) para escalar el *rendimiento*[cite: 4].

**Cita Bibliográfica formal:** Stallings, W. (2017). *Operating Systems: Internals and Design Principles* (9th ed.). Pearson. Capítulo 5-6.
